# Advay Bhatia — Developer Portfolio

Personal portfolio website inspired by dark glassmorphism minimalism, built with zero-dependency static HTML5, CSS3, and vanilla JavaScript for instant GitHub Pages deployment.

## Features

- **Dark Glassmorphism UI** (`#111111` base, `#FFB400` accent, `DM Sans` + `Inter` typography)
- **Floating Navigation** with scroll-spy active indicators and mobile bottom dock
- **Interactive Skill-to-Project Highlighting** on hover in the About section
- **Cursor-Tracking Spotlight Glow** across glass cards
- **Responsive Timeline & Project Showcase** for experience, education, and featured builds

## Customization

- **Profile Photo**: Add your portrait as `profile.jpg` in the project root. Until added, it falls back automatically to `assets/hero-avatar.svg`.
- **Content & Links**: Edit `index.html` to add more projects, experience entries, or a resume link.
- **Accent Color**: Change `--accent` in `style.css` if you prefer a different highlight color.

## Local Preview

Open `index.html` directly in any browser.
